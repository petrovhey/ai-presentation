## 2026-04-29 21:54 CST — AI Monkey v4 Final (RoboMonkey переименован)

### Переименование
- **RoboMonkey** → **AI Monkey** — во всех файлах: manifest name, UI заголовки, промпт, README
- Причина: Саша попросил

### Добавлено: chrome.userScripts API
- В `manifest.json` добавлен permission `"userScripts"` — официальный Chrome API для userscripts
- При установке в `chrome://extensions/` появляется toggle **"Разрешить пользовательские скрипты"**
- Без этого toggle скрипты не инжектируются — стандартный механизм безопасности Chrome

### v4: Исправлено 6 багов

| # | Баг | Причина | Фикс |
|---|-----|---------|------|
| 1 | Скрипт создаётся, но ничего не появляется | `wrapUserScript()` возвращал `undefined` | `buildScriptString()` — возвращает JS-строку |
| 2 | Ошибка `Sync failed` | `chrome.userScripts` API отсутствует в стабильном Chrome | **Dual mode**: fallback на `chrome.scripting.executeScript` |
| 3 | "Новый скрипт" меняет предыдущий | Inline `onclick` блокируется CSP Chrome | `data-action` + event delegation |
| 4 | Чат не обновляется при смене сайта | `chatHistory` общий для всех сайтов | **Chat keyed by domain** — каждый сайт свой чат |
| 5 | Кнопки в скриптах не работают | CSP Chrome Extension блокирует inline `onclick` | Все inline onclick убраны |
| 6 | Load all models не работал | Inline `onclick="loadModels()"` | `data-action="loadModels"` |

### Технические изменения v4
- **background.js**: полная перезапись — `syncUserScripts()` (userScripts API) + `syncAllScriptsFallback()` (scripting API). `buildScriptString()` вместо `wrapUserScript()` — возвращает строку, не `undefined`
- **sidepanel.js**: полная перезапись — `setupEventDelegation()` на `document.body`, все кнопки через `data-action`. `updateChatForCurrentPage()` — chatHistory keyed по `currentDomain` (hostname). `chrome.storage.local` хранит `chatsByDomain`
- **sidepanel.html**: все `onclick="..."` заменены на `data-action="..."`
- **editor.js**: полная перезапись — `setupEditorEvents()` с event delegation. `renderMatches()` генерирует `data-action="removeMatch"` вместо inline `onclick`
- **editor.html**: все `onclick` заменены на `data-action`
- **popup.js**: уже был без inline onclick (ранее пофикшен)

### Dual mode инъекция
```
if (chrome.userScripts?.register) {
  // Primary: chrome.userScripts API (требует toggle)
  await chrome.userScripts.register(...)
} else {
  // Fallback: chrome.scripting.executeScript (всегда работает)
  await chrome.scripting.executeScript({ target: { tabId }, func: runUserScript, args, world: 'MAIN' })
}
```
- `runUserScript` использует `new Function(code)` с GM_* API в scope — CSP-safe

### Чат привязан к сайту
- `currentDomain = new URL(tab.url).hostname`
- `chatHistory` сохраняется в `chrome.storage.local` под ключом `chatsByDomain[domain]`
- При открытии Dashboard загружается чат для текущего сайта
- При смене вкладки/сайта — другой чат
