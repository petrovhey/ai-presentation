# RoboMonkey v3

AI Userscript Builder & Manager для Chrome (Manifest V3).

## Что нового в v3

- **🤖 AI-диалог (Claude-style prompt)** — описываешь что хочешь, AI задаёт уточняющие вопросы если нужно
- **🌐 Язык пользователя** — пишешь по-русски → ответ на русском. По-английски → на английском. Автоопределение.
- **🔧 Автоустановка** — сгенерированный скрипт НЕ показывается в чате, а сразу сохраняется и активируется
- **✅ Готово** — в чате только результат: "Скрипт создан, обнови страницу"
- **📝 Ручной ввод модели** — введи любой ID модели с OpenRouter + кнопка Test для проверки
- **🔄 Load All Models** — теперь работает корректно (берёт ключ прямо из поля)

## Установка

1. Распакуйте папку `v2` (да, папка называется v2, но это v3 по функционалу)
2. Chrome → `chrome://extensions/` → включите **Developer mode**
3. **Load unpacked** → выберите папку `v2`
4. Кликните на иконку 🐵 → откроется **Popup**
5. Нажмите **Open Dashboard** → откроется боковая панель
6. Перейдите на вкладку **⚙️ Settings** → введите OpenRouter API Key
7. Выберите модель из списка или введите свою в поле **Custom Model**
8. Нажмите **Test** чтобы проверить что модель работает
9. Нажмите **Save Settings**

## Как создать скрипт

1. Во вкладке **🤖 Chat** нажмите **🛠️ Create New Script**
2. Опишите что хотите, например: "На YouTube убери все баннеры и сделай тёмную тему по умолчанию"
3. AI либо задаст вопросы, либо сразу приступит
4. Скрипт генерируется **автоматически** и устанавливается
5. В чате видите: "✅ Готово! Скрипт «...» создан и активирован. Обнови страницу."
6. Обновляете страницу — скрипт работает

## Настройки

- **Auto-install generated scripts** — когда включено, код не показывается в чате, а сразу устанавливается. Когда выключено — код показывается и вы сами решаете ставить или нет.

## Где настройки?

Dashboard → вкладка ⚙️ **Settings**
