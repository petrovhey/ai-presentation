# Промпт для blink.new: RoboMonkey — AI-расширение для генерации и управления Userscripts

## Название проекта
RoboMonkey — AI Userscript Builder & Manager

## Тип проекта
Chrome Extension (Manifest V3) + встроенная веб-панель (popup / side panel / full-page dashboard)

---

## Концепция (1 абзац)
Создай Chrome-расширение, которое является AI-ассистентом для создания, редактирования и управления userscripts (как Tampermonkey/Greasemonkey). Пользователь описывает задачу текстом — AI генерирует JavaScript-скрипт, который автоматически инжектируется на нужные сайты. Расширение имеет встроенный чат с AI (через OpenRouter API с выбором модели), менеджер скриптов с версионированием, редактор кода и возможность импорта скриптов с GreasyFork.

---

## Архитектура расширения

### Структура Manifest V3
```
- manifest.json (V3)
- background.js (service worker) — управление userscripts, API-запросы к OpenRouter
- content_script_injector.js — инжектит userscripts на страницы
- popup.html / popup.js — мини-дашборд
- sidepanel.html / sidepanel.js — основной интерфейс (чат + менеджер скриптов)
- editor.html / editor.js — редактор кода для userscripts
- storage.js — работа с chrome.storage.local (скрипты, настройки, история чата)
```

- Быстрый доступ: список активных скриптов для текущего сайта (вкл/выкл)

- Индикатор статуса соединения с OpenRouter

#### 2. Side Panel / Dashboard (основной интерфейс)
**Левая колонка — меню:**

- 📜 My Scripts — библиотека всех userscripts
- 🌐 GreasyFork — поиск и импорт скриптов
- ⚙️ Settings — настройки API и моделей

**Правая область — контент:**

##### Экран «AI Chat»
- Чат-интерфейс (как в ChatGPT): сообщения пользователя слева, AI справа
- Поле ввода снизу + кнопка отправки
- AI отвечает текстом + блоками кода (если генерирует скрипт)
- Каждый сгенерированный скрипт имеет кнопки: «Установить скрипт», «Редактировать», «Копировать», «Попробовать ещё раз»
- Контекст чата сохраняется (история диалога не теряется)
- Системный промпт по умолчанию: «Ты — эксперт по userscripts (Tampermonkey/Greasemonkey). Генерируй только рабочий JavaScript-код с метаданными @match, @grant. Не используй внешние библиотеки без необходимости.»

##### Экран «My Scripts»
- Список всех userscripts в виде карточек:
  - Название, описание, статус (вкл/выкл)
  - На каких сайтах работает (@match)
  - Последнее обновление
  - Количество версий
- Фильтры: Все / Активные / Неактивные / По сайту
- Кнопки на карточке: Вкл/выкл | Редактировать | Удалить | Версии
- Кнопка «Создать скрипт вручную» — открывает редактор с пустым шаблоном

##### Экран «GreasyFork»
- Поисковая строка для поиска скриптов на GreasyFork

- При импорте — скрипт парсится, метаданные (@name, @match, @grant) извлекаются, скрипт добавляется в библиотеку
- Возможность импорта по прямой ссылке (paste URL → fetch → install)

##### Экран «Settings»
- **OpenRouter API Settings:**
  - Поле для API Key (OpenRouter)
  - Кнопка «Проверить соединение»
  - **Выпадающий список моделей** — динамически загружается с `/api/v1/models` с OpenRouter:
    - Показывать: название модели, провайдера, цену за 1K токенов
    - Возможность фильтрации: «Показать только бесплатные» (где pricing.prompt === 0 и pricing.completion === 0)
    - Группировка по провайдеру
  - Поле для системного промпта (редактируемое)
  - Ползунок Temperature (0–1.5)

- **Extension Settings:**
  - Горячая клавиша для открытия дашборда
  - Авто-обновление GreasyFork-скриптов (да/нет)
  - Тема оформления (светлая / тёмная)

## Функциональные требования

### AI-генерация скриптов
1. Пользователь пишет запрос в чат: «Сделай скрипт, который скрывает рекламу на youtube.com»
2. Расширение отправляет запрос в OpenRouter API (`POST /api/v1/chat/completions`) с:
   - model: выбранная модель из настроек
   - messages: системный промпт + история чата + новый запрос
   - temperature, max_tokens
3. AI отвечает текстом + JavaScript-кодом (в markdown-блоке ```javascript)
4. Расширение парсит код, автоматически добавляет метаданные если их нет:
   ```javascript
   // ==UserScript==
   // @name         [AI Generated] Название скрипта
   // @match        https://*.youtube.com/*
   // @grant        none
   // @version      1.0
   // @description  Сгенерировано AI
   // ==/UserScript==
   ```
5. Кнопка «Установить» — сохраняет в chrome.storage.local, скрипт сразу активен

### Управление Userscripts (менеджер)
1. **CRUD операции:**
   - Создать: через AI-чат или вручную в редакторе
   - Читать: список с метаданными
   - Обновить: редактирование в редакторе
   - Удалить: с подтверждением
2. **Активация/деактивация:** один клик — скрипт включается/выключается без удаления
3. **Редактор кода:**
   - Встроенный редактор с подсветкой синтаксиса (CodeMirror 6 или Monaco Editor lightweight)
   - Поддержка JavaScript + специфичные для userscripts сниппеты (@match, @grant, GM_*)
   - Нумерация строк, автоформатирование
   - Предпросмотр метаданных (парсинг header)
   - Кнопки: Сохранить | Сохранить как новую версию | Отмена | Тест на текущей вкладке
4. **Версионирование:**
   - Каждое сохранение скрипта создаёт новую версию
   - Хранятся все версии с меткой времени
   - Возможность откатиться к любой предыдущей версии («Версии» → выбрать → «Восстановить»)
   - Сравнение версий (diff view, опционально)
   - Ограничение: хранить последние 20 версий (старые удаляются автоматически)
5. **Инжекция скриптов:**
   - Background service worker слушает chrome.tabs.onUpdated
   - Для каждой вкладки проверяет URL против @match паттернов всех активных скриптов
   - Совпадающие скрипты инжектируются через chrome.scripting.executeScript (после загрузки DOM)
   - Поддержка @run-at (document-start, document-end, document-idle)
   - Эмуляция GM_* API (GM_setValue, GM_getValue, GM_xmlhttpRequest и др.) через chrome.storage + fetch прокси

### Интеграция с GreasyFork
1. Поиск по API GreasyFork (или парсинг HTML если API ограничен)
2. Импорт скрипта по ID или прямой ссылке
3. Авто-обновление: при включённой настройке раз в сутки проверяет обновления для импортированных скриптов (сравнивает @version)

### OpenRouter интеграция
1. **Список моделей:**
   - При открытии Settings или при первом запуске — запрос к `https://openrouter.ai/api/v1/models`
   - Кэширование списка на 24 часа
   - Отображать: название, провайдер, цену (input/output)
   - Фильтр «Только бесплатные» убирает модели где цена > 0
   - Сортировка: по цене, по популярности
2. **Запросы:**
   - Endpoint: `https://openrouter.ai/api/v1/chat/completions`
   - Headers: Authorization: Bearer {api_key}, HTTP-Referer: {extension_id}, X-Title: RoboMonkey
   - Body: model, messages, temperature, max_tokens
3. **Обработка ошибок:**
   - 401 — показать «Неверный API ключ»
   - 429 — показать «Превышен лимит запросов, попробуйте позже»
   - 402 — показать «Недостаточно средств на OpenRouter»
   - Остальные — «Ошибка AI: {message}»
4. **Индикатор:**
   - Во время генерации — анимированные точки «AI думает...»
   - После ответа — показать использованные токены (если возвращены в response)

### Хранение данных
- Использовать chrome.storage.local
- Структура:
  ```json
  {
    "scripts": [
      {
        "id": "uuid",
        "name": "Скрыть рекламу YouTube",
        "description": "...",
        "code": "// ==UserScript==...",
        "matches": ["https://*.youtube.com/*"],
        "grants": ["none"],
        "enabled": true,
        "createdAt": 1234567890,
        "updatedAt": 1234567890,
        "source": "ai" // или "manual", "greasyfork"
      }
    ],
    "versions": {
      "script-uuid": [
        {"version": 1, "code": "...", "createdAt": 123, "comment": "Initial"},
        {"version": 2, "code": "...", "createdAt": 124, "comment": "Fixed bug"}
      ]
    },
    "settings": {
      "apiKey": "...",
      "selectedModel": "openai/gpt-4o-mini",
      "temperature": 0.7,
      "systemPrompt": "...",
      "theme": "dark"
    },
    "chatHistory": [
      {"role": "user", "content": "..."},
      {"role": "assistant", "content": "..."}
    ]
  }
  ```

### Безопасность
1. API Key хранить в chrome.storage.local (зашифровано через crypto.subtle если возможно, или как есть — blink.new сам решит)
2. Скрипты исполняются в sandbox-контексте страницы (content script isolation)
3. GM_xmlhttpRequest проксируется через background service worker (CORS-прокси)
4. Подтверждение перед установкой скриптов с внешних источников (GreasyFork)

## Граничные случаи и обработка ошибок

1. Пользователь ввёл невалидный API Key — показать красное сообщение, не пытаться отправлять запросы
2. AI вернул код без метаданных — автоматически добавить @match для текущего сайта или *://*/*
3. Скрипт содержит ошибку синтаксиса — при сохранении показать warning, но позволить сохранить (Tampermonkey тоже так делает)
4. Достигнут лимит версий (20) — удалить самую старую версию при создании новой
5. Пользователь удаляет скрипт — подтверждение + предложение экспортировать .user.js файл
6. Сайт использует CSP, блокирующий inline-скрипты — инжектировать через скрипт-тег с nonce или через chrome.scripting

## Финальная инструкция для blink.new

Создай полноценное Chrome-расширение (Manifest V3) — AI-менеджер userscripts. Основные возможности:

1. Чат-интерфейс в sidepanel где пользователь общается с AI (OpenRouter API, выбор любой модели включая бесплатные) для генерации JavaScript-userscripts.
2. Автоматическое добавление метаданных (@match, @grant) к сгенерированным скриптам.
3. Менеджер скриптов: список всех скриптов с возможностью включать/выключать, редактировать, удалять.
4. Встроенный редактор кода (CodeMirror) с подсветкой синтаксиса.
5. Система версионирования: каждое сохранение скрипта создаёт версию, можно откатиться к любой предыдущей.
6. Инжекция скриптов на веб-страницы через background service worker согласно @match паттернам.
7. Импорт скриптов с GreasyFork по поиску или прямой ссылке.
8. Настройки: API Key OpenRouter, выпадающий список моделей (с фильтром «только бесплатные»), системный промпт, temperature.
9. Хранение всего в chrome.storage.local.
10. Тёмная тема, современный UI, адаптация под sidepanel Chrome.

Используй JavaScript (ES2022+), Manifest V3, chrome.storage API, Fetch API. Обеспечь эмуляцию GM_* функций Tampermonkey. Сделай UI минималистичным и быстрым.
