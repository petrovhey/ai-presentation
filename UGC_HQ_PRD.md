# UGC HQ — Product Requirements Document
## Платформа управления контент-креаторами для маркетплейсов

**Версия:** 1.0  
**Дата:** 2026-04-29  
**Для:** atoms.dev (AI-разработка под ключ)

---

## 1. Суть продукта

SaaS-платформа для брендов на WB/Ozon, которая:
- Находит и отбирает UGC-креаторов (блогеров, обычных людей)
- Выдает им уникальные подменные артикулы для съемки
- Собирает контент и отслеживает его эффективность (переходы → корзины → заказы)
- Автоматизирует выплаты креаторам

**Ключевая фишка:** Подменные артикулы позволяют видеть точную аналитику по каждому креатору — сколько переходов, добавлений в корзину, заказов именно через его контент.

---

## 2. Зачем это нужно (Pain & Gain)

### Pain (боль)
- Бренды ищут креаторов вручную через Telegram, Excel, Google-таблицы
- Не понятно, какой контент продает, а какой — нет
- Креаторы делают видео "в потолок", без понимания что нужно бренду
- Выплаты — ручной беспорядок: кто сколько заработал, когда платить
- Нет системного подхода: каждый раз всё начинается с нуля

### Gain (выгода)
- Автоматический поиск и фильтрация креаторов через форму/анкету
- Точная атрибуция: каждый креатор видит сколько он продал
- Контент сразу попадает в библиотеку бренда ( reuse для рекламы )
- Автоматические выплаты по факту заказов
- Масштабирование: 10 → 100 → 1000 креаторов без хаоса

## 3. Архитектура подменных артикулов (Core Mechanic)

### Принцип работы
```
Бренд создает товар «Витамин D3» (арт. 123456)
   ↓
Генерирует 5 подменных артикулов:
  - 123456-A (для креатора Иванов)
  - 123456-B (для креатора Петрова)
  - 123456-C (для креатора Сидорова)
  - 123456-D (для креатора Козлова)
  - 123456-E (для креатора Новикова)
   ↓
Каждый артикул — это тот же товар, но с уникальным SKU
   ↓
WB/Ozon собирают аналитику по каждому SKU отдельно:
  - Просмотры карточки
  - Переходы
  - Добавления в корзину
  - Заказы
  - Выручка
   ↓
Данные подтягиваются в UGC HQ через API маркетплейсов
   ↓
Креатор видит свою статистику, бренд видит общую
```

### Техническая реализация
- **WB:** API Статистики (статистика по nmId / артикулу). Подменный артикул = отдельный nmId, привязанный к тому же товару через "объединение в карточку" или как вариант товара.
- **Ozon:** API Seller/Performance. Подменный артикул = отдельный offer_id, привязанный к тому же product_id.
- **Альтернатива (если API не дает):** Ссылки с UTM/параметрами + лендинг-редирект. Но артикулы точнее.

## 4. Этапы работы платформы (User Flow)

### ЭТАП 1: Создание кампании (Бренд)

**Что делает бренд:**
1. Заходит в UGC HQ
2. Создает кампанию: «Съемка Витамина D3, май 2026»
3. Указывает:
   - Товар (выбор из каталога или добавление нового)
   - Количество креаторов (например, 20)
   - Тип контента (Reels/Shorts/Stories/Фото)
   - Бюджет / ставка (например, 15% от заказов или фикс 500₽ за видео)
   - Требования к контенту (хронометраж, что показать, что не показать)
   - Сроки
4. Система автоматически генерирует N подменных артикулов
5. Кампания получает уникальную ссылку для регистрации креаторов

### ЭТАП 2: Регистрация креаторов (Креатор)

**Что делает креатор:**
1. Получает ссылку на кампанию (из Telegram, соцсетей, рекламы)
2. Открывает лендинг с описанием:
   - Что за бренд
   - Что за товар
   - Сколько платят
   - Какие требования
   - Примеры хорошего контента
3. Нажимает «Стать креатором»
4. Заполняет форму:
   - ФИО
   - Телефон / Telegram
   - Email
   - Ссылки на соцсети (Instagram, TikTok, VK)
   - Количество подписчиков
   - Город
   - Опыт в UGC (да/нет, примеры работ)
   - Видео-selfie (30 сек, рассказать о себе)
   - Тестовое задание (опционально: снять 15-сек видео с товаром / мокапом)
5. Отправляет анкету

### ЭТАП 3: Модерация и отбор (Бренд / Менеджер)

**Что делает платформа:**
1. Собирает все анкеты в единый список
2. Автоматически проверяет:
   - Подписчики (минимальный порог, если задан)
   - Активность аккаунта (посты за последние 30 дней)
   - Гео (если нужно)
3. AI-ассистент делает предварительную оценку:
   - Качество видео
   - Активность
   - Подходят ли под ТЗ
   - Скор 1–10
4. Менеджер бренда:
   - Просматривает отфильтрованный список
   - Смотрит профили, видео
   - Апрувит / реджектит
   - Может написать комментарий
5. Одобренным креаторам:
   - Приходит уведомление в Telegram / email
   - Выдается подменный артикул
   - Открывается доступ к личному кабинету

### ЭТАП 4: Производство контента (Креатор)

**Что делает креатор:**
1. Получает товар (доставка или самовывоз)
2. Снимает контент по ТЗ бренда
3. Загружает готовое видео/фото в личный кабинет
4. Указывает:
   - Площадки публикации (Instagram, TikTok, VK, etc.)
   - Дата публикации
   - Ссылка на пост (если уже опубликовал)
5. Модератор бренда проверяет:
   - Соответствие ТЗ
   - Качество
   - Наличие артикула / ссылки
   - Апрувит / просит доработку
6. После апрува:
   - Контент переходит в статус «Активно»
   - Подменный артикул активируется для отслеживания
   - Креатор может публиковать

### ЭТАП 5: Трекинг и аналитика (Система)

**Что собирает платформа (автоматически):**
1. Каждые 6 часов (или по запросу):
   - Запрашивает статистику по каждому подменному артикулу через API WB/Ozon
   - Обновляет данные в реальном времени
2. Для каждого креатора показывает:
   - Просмотры карточки
   - Переходы по ссылке
   - Добавления в корзину
   - Заказы
   - Выручка
   - Комиссия креатору (например, 15%)
3. Для бренда показывает:
   - Общая сводка по кампании
   - Топ-креаторы по продажам
   - ROI кампании
   - Сравнение с предыдущими кампаниями
   - Стоимость привлечения заказа (CAC)

### ЭТАП 6: Выплаты (Система)

**Варианты оплаты (настраивается при создании кампании):**

**A. Процент от заказов (основной)**
- Креатор получает X% от суммы заказов через его артикул
- Начисления обновляются ежедневно
- Выплаты:
  - Автоматически по достижении порога (например, 1000₽)
  - Или по расписанию (раз в неделю/месяц)
  - Через integration: ЮKassa, СБП, перевод на карту

**B. Фикс за контент**
- Фиксированная сумма за каждое апрувнутое видео
- Выплата после модерации контента

**C. Гибрид**
- Фикс за съемку + % от продаж

**Что делает платформа:**
- Считает комиссии автоматически
- Генерирует отчет по выплатам
- Отправляет креаторам уведомление: «Вы заработали X₽, выплата придет Y числа»
- Интеграция с платежной системой для массовых выплат

### ЭТАП 7: Библиотека контента (Бренд)

**Что накапливается:**
- Все апрувнутые видео/фото в единой медиатеке
- Метаданные: креатор, дата, площадка, статистика
- Статусы: «Свободно», «В рекламе», «Архив»
- Бренд может:
  - Скачивать контент для рекламных кампаний
  - Использовать в своих соцсетях
  - Запускать в рекламу WB/Ozon
  - Отмечать лучшие работы

## 5. Роли пользователей

| Роль | Что делает | Доступ |
|------|-----------|--------|
| **Владелец (бренд)** | Создает кампании, видит финансы, управляет менеджерами | Полный |
| **Менеджер** | Модерирует креаторов, апрувит контент, следит за статистикой | Кампании, креаторы, контент |

| **Админ платформы** | Техподдержка, управление пользователями, биллинг | Всё |

## 6. Структура данных (основные сущности)

### Brand (Бренд)
- id, name, logo, contact_email, contact_phone
- marketplace_accounts: [{platform, api_key, seller_id}]
- balance, billing_info

### Product (Товар)
- id, brand_id, name, description, category
- base_article (основной артикул WB/Ozon)
- images, price, commission_rate

### Campaign (Кампания)
- id, brand_id, name, status (draft/active/paused/completed)
- product_id, creator_count, content_type
- budget_type (percent/fixed/hybrid), commission_percent, fixed_amount
- requirements (текст ТЗ)
- dates: start_date, end_date
- registration_link (уникальный URL)

### Article (Подменный артикул)
- id, campaign_id, product_id
- code (уникальный, например «123456-A»)
- creator_id (кто назначен)
- status (free/assigned/active/completed)
- stats: views, clicks, carts, orders, revenue

### Creator (Креатор)
- id, status (pending/approved/rejected/blocked)
- profile: name, phone, telegram, email, city
- social_links: {instagram, tiktok, vk, youtube}
- followers_count, experience_level
- portfolio: [video_urls]
- balance, total_earned

### Application (Заявка креатора)
- id, campaign_id, creator_id
- status (pending/approved/rejected)
- form_data: {all fields from registration}
- selfie_video_url, test_task_url
- ai_score, manager_comment
- created_at, reviewed_at

### Content (Контент)
- id, campaign_id, creator_id, article_id
- type (video/image/story)
- file_url, thumbnail_url
- platforms: [instagram, tiktok, vk]
- post_url, publish_date
- status (uploaded/pending/approved/rejected)
- moderation_comment
- stats: views, likes, comments, shares (если доступно)

### Payout (Выплата)
- id, creator_id, campaign_id
- amount, status (pending/paid/failed)
- type (percent/fixed/bonus)
- period_start, period_end
- paid_at, transaction_id

## 7. Интеграции

### Обязательные
| Сервис | Для чего |
|--------|---------|
| **WB API** | Статистика по артикулам, заказы, выручка |
| **Ozon API** | Статистика по offer_id, продажи |
| **Telegram Bot** | Уведомления креаторам и менеджерам |
| **Email** | Письма: подтверждение регистрации, выплаты |

### Опциональные (Phase 2)
| Сервис | Для чего |
|--------|---------|
| **ЮKassa / СБП** | Автоматические выплаты креаторам |
| **Instagram API** | Проверка публикаций, подписчиков |
| **TikTok API** | Проверка видео, статистика |
| **AI (Kimi / Claude / GPT)** | Оценка качества контента, генерация ТЗ |

## 9. MVP — минимальный работающий продукт

### Что обязательно для запуска (2–3 недели):
1. Регистрация бренда + создание кампании
2. Форма регистрации креаторов + загрузка анкет
3. Модерация анкет (ручная, список в админке)
4. Генерация подменных артикулов (вручную или авто)
5. Личный кабинет креатора: артикул, ТЗ, загрузка видео
6. Модерация контента
7. Ручная загрузка статистики из WB (CSV) — если API нет
8. Таблица выплат (ручной расчет)

### Что добавить потом (Phase 2):
- API WB/Ozon для автообновления статистики
- Telegram-бот для уведомлений
- Автоматические выплаты
- AI-модерация анкет
- Библиотека контента с поиском
- Интеграция с Instagram/TikTok API
- Реферальная программа для креаторов

|-------|------|-------------|
| **Start** | Бесплатно | 1 кампания, 5 креаторов, ручная статистика |
