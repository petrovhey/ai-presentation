## Слайд 2. Что такое ИИ — кратко (исправлено)

**Искусственный интеллект** — программа, которая учится на данных и делает выводы, которые раньше требовали человека.

**Как работает:**
- **Обучение** — модель «читает» огромные массивы текста/кода/изображений и запоминает закономерности
- **Инференс** — при получении запроса она предсказывает наиболее вероятный ответ, основываясь на том, что выучила
- **Токены** — текст разбивается на маленькие кусочки (токены), модель обрабатывает их за один проход. 1 токен ≈ 0.75 слова

**Модальности — что модель может воспринимать на вход:**
| Модальность | Пример задачи |
|---|---|
| **Текст** | Написать письмо, проанализировать документ, ответить на вопрос |
| **Код** | Написать скрипт, исправить баг, объяснить чужой код |
| **Изображение** | Загрузить скриншот с графиком — модель прочитает цифры и сделает выводы. Загрузить фото товара — найдёт аналоги. Загрузить скан документа — извлечёт текст |
| **Аудио** | Закинуть запись совещания — получить расшифровку и выделить action items. Загрузить голосовое сообщение — в текст |
| **Видео** | Загрузить ролик — получить расшифровку, найти ключевые моменты, сделать summary |
| **Документы (PDF, Excel, Word)** | Скормить договор — найти рисковые пункты. Скормить отчёт — выделить тренды. Скормить таблицу — найти ошибки |
| **Многомодальность** | Скинуть скриншот с вопросом «почему упали продажи?» — модель увидит график и даст анализ. Скинуть фото чека — извлечёт сумму и дату |

**Ключевое:** модель не «думает» — она статистически предсказывает, что должно быть дальше. Но при огромном объёме данных это выглядит как понимание. Для работы это означает: чётко формулируйте задачу и проверяйте результат.

## Слайд 15. AI-разработка без программиста (новый слайд)

**Что это:** Платформы, где вы описываете сайт/приложение текстом — а ИИ пишет код и сразу показывает результат.

| Платформа | Что делает | Для чего |
|---|---|---|
| **Lovable** | Генерация полноценных веб-приложений и сайтов из текстового описания | Быстро создать MVP, лендинг, внутренний инструмент без разработчика |
| **Blink.new** | Создание сайтов и веб-приложений с AI-дизайном | Когда нужен красивый сайт с нуля за минуты, а не часы |
| **Bolt.new** | AI-разработка на базе Next.js и React — пишет код, показывает превью | Для тех, кто хочет настоящий код под капотом (можно забрать и доработать) |
| **Hercules.app** | Создание внутренних бизнес-приложений (CRM, дашборды, формы) из описания | Автоматизация внутренних процессов без IT-отдела |

**Общий принцип:** Вы пишете «сделай сайт для приёма заявок с полями имя, телефон, выбор услуги и отправкой в Telegram» — платформа генерирует работающий сайт. Не нужно уметь кодить.

**Для бизнеса:**
- Прототипы за часы, а не недели
- Внутренние инструменты без нагрузки на IT
- Экономия на фрилансерах для простых задач

## Слайд 16. Задачи по отделам (новый слайд)

| Отдел | Что может делать ИИ | Примеры |
|---|---|---|
| **Бухгалтерия** | Распознавание первичных документов, сверка данных, проверка соответствия проводок, анализ движения денежных средств, подготовка пояснительных записок | Загрузить 100 сканов счетов — получить сводную таблицу. Сверить данные из 1С с банковской выпиской |
| **Финансы** | Прогнозирование денежных потоков, анализ инвестиций, построение бюджетов, сценарное моделирование, проверка финансовых моделей | «Построй 3 сценария на год при росте выручки 10/20/30%». Проверить формулы в Excel-модели |
| **Юристы** | Анализ договоров, выявление рисков, сравнение редакций, подготовка претензий, поиск судебной практики, формирование шаблонов | Загрузить договор — выделить пункты с неблагоприятными условиями. Сравнить две редакции NDA |
| **Продакт-менеджеры** | Анализ пользовательских отзывов, генерация user stories, прототипирование, A/B-тесты гипотез, написание ТЗ, исследование конкурентов | Скормить 500 отзывов из App Store — выделить топ-10 проблем. Написать ТЗ на интеграцию |
| **Коммерческий департамент** | Скрипты продаж, анализ воронки, работа с возражениями, подготовка КП, анализ конкурентов, генерация писем | «Напиши 5 вариантов письма для реактивации клиентов, не купивших 90 дней». Проанализировать цены конкурентов |
| **Топ-менеджеры** | Стратегические сессии, анализ отраслевых трендов, подготовка презентаций для совета директоров, структурирование мыслей, due diligence | «Проанализируй 3 варианта выхода на новый рынок с рисками и бюджетом». Структурировать стратегию в понятный план |
| **Аналитики** | Обработка больших массивов данных, построение дашбордов, SQL-запросы, статистический анализ, прогнозирование, визуализация | Загрузить CSV с транзакциями — найти аномалии и паттерны. Написать SQL для сложного отчёта |
| **HR и подбор** | Составление вакансий, скрининг резюме, подготовка вопросов для интервью, адаптационные планы, анализ вовлечённости | «Проанализируй 50 резюме — выдели топ-10 кандидатов под эти критерии». Написать план адаптации на первые 30 дней |

**Важно:** ИИ — ассистент, не замена. Проверяйте финальные решения, особенно в юридических и финансовых вопросах.

## Слайд 17. Рекомендации по работе с ИИ (новый слайд)

**1. Если не уверены — обсудите с другой моделью**
Не доверяйте одному ответу на критические вопросы. Задайте тот же вопрос Claude, GPT и DeepSeek. Если все три говорят одно — можно доверять. Если расходятся — копайте глубже.

**2. Важнее не входные данные, а то что вы хотите получить**
Плохой запрос: «Вот отчёт, сделай что-нибудь». Хороший запрос: «Из этого отчёта выдели 3 главных тренда за квартал и предложи 2 действия для каждого». Формулируйте результат.

**3. Вначале план, потом реализация**
Сначала попросите ИИ составить план решения задачи и согласуйте его. Только потом просите выполнять. Это экономит время на переделках.

**4. Всегда уточняйте «Есть вопросы? Всё ли понятно?»**
Лучшие результаты даёт не монолог, а диалог. Заставьте ИИ задать уточняющие вопросы перед выполнением — результат будет точнее.

**5. Разбивайте сложные задачи на шаги**
Не просите «напиши бизнес-план» в одном сообщении. Разбейте: 1) структура, 2) рынок, 3) экономика, 4) риски. Каждый шаг отдельно.

**6. Давайте контекст — кто вы и для кого результат**
«Ты финансовый директор среднего бизнеса, готовишь презентацию для совета директоров. Нужно объяснить, почему кассовый разрыв вырос на 20%» — результат будет в разы точнее, чем без контекста.

**7. Проверяйте факты, особенно даты и цифры**
ИИ уверенно выдумывает даты, ссылки и данные. Всегда перепроверяйте фактчекингом или поиском.

**8. Используйте системные промпты для повторяющихся задач**
Если каждый день анализируете одно и то же — создайте шаблон: «Ты аналитик. Каждый раз, когда я кидаю CSV, выделяй: аномалии, топ-3 тренда, рекомендации». Экономит время.

**9. Не копируйте конфиденциальные данные в западные модели без VPN/защиты**
Для чувствительной информации используйте локальные модели (DeepSeek, Qwen) или корпоративные тарифы с гарантиями неиспользования данных для обучения.
