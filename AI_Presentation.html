Чат vs Агент — критическая разница

🤖 Чат-бот

Вы спрашиваете → получаете ответ

  • Пишет черновик документа
  • Объясняет сложное просто
  • Анализирует таблицу
  • Ищет информацию

Как очень умный коллега, который всегда на связи

🦾 Агент (как я — Илья)

Вы даёте задачу → он её выполняет

  • Сам заходит в системы
  • Отправляет письма
  • Обновляет таблицы
  • Запускает рекламу
  • Анализирует данные из API

Не советует — делает

Пример разницы: Чат: «Какая у нас выручка в марте?» → вам дают инструкцию, где посмотреть Агент: «Пришли отчёт по выручке за март» → сам заходит в Метрику/CRM, собирает данные, формирует PDF и присылает

Бухгалтерия

Что ИИ делает

  • Сверка документов — счёт, накладная, акт. ИИ находит расхождения за минуты
  • Проверка контрагентов — заходит на ФНС/Контур, проверяет риски
  • Авто-заполнение — декларации, формы, отчётность
  • Анализ отчётов — графики движения денег, прогноз кассовых разрывов
  • Напоминания — «за 3 дня до сдачи НДС», «проверить авансовые 10-го»

Юристы

Что ИИ делает

  • Проверка договоров на риски — выделяет нестандартные условия, отсутствие штрафов, автопролонгацию
  • Генерация документов — ДС, претензии, письма по шаблону
  • Мониторинг законов — отслеживает изменения в 44-ФЗ, 223-ФЗ, НК
  • Сравнение версий — показывает, что именно поменялось между редакциями

План внедрения

Неделя 1

Разведка
Создать аккаунты ChatGPT / Claude / Kimi. Протестировать на 1–2 реальных задачах. Зафиксировать время «до» и «после».

Недели 2–3

Пилот
3 конкретные задачи на ИИ в каждом отделе. Настроить шаблоны промптов. Назначить «эксперта по ИИ».

Неделя 4

Масштабирование
Обмен опытом между отделами. Фиксация экономии времени. Подключение платных версий при необходимости.

Месяц 2

Автоматизация
Настройка агентов для повторяющихся процессов. Интеграция с CRM, 1С, почтой. Мониторинг эффективности.

Бюджет

Бесплатно Kimi, Gemini, Perplexity (базовый) — для старта хватит

Безопасность

✅ Можно

  • Обезличенные данные (без ФИО, ИНН, телефонов)
  • Общие описания процессов и политик
  • Открытые документы: ТЗ, маркетинг, шаблоны
  • Анализ рынка и конкурентов
  • Генерация текстов с вымышленными примерами

❌ Нельзя в публичные ИИ

  • Персональные данные сотрудников и клиентов
  • Коммерческая тайна (себестоимость, маржа, поставщики)
  • Доступы к банк-клиенту, CRM, 1С
  • Подписанные договоры с реальными реквизитами
  • Информация о контрагентах без их согласия

Решение для конфиденциальных задач

Локальные модели (Llama, Mistral на вашем сервере)
Корпоративные подписки с NDA и изоляцией данных
Правило: если сомневаетесь — замените реальные данные на вымышленные (Иванов → Петров, ООО "Ромашка" → ООО "Пример")
