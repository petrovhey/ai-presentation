Что такое ИИ

Программа, которая учится на данных и делает выводы, которые раньше требовали человека

01

Обучение

Модель «читает» огромные массивы текста, кода, изображений — и запоминает закономерности. Это как если бы человек прочитал миллионы книг за одну ночь.

02

Инференс

При получении запроса модель предсказывает наиболее вероятный ответ, основываясь на том, что выучила. Не думает — считает вероятности.

03

Токены

Текст разбивается на маленькие кусочки. 1 токен ≈ 0.75 слова. Контекстное окно = сколько токенов модель помнит одновременно.

Модальности

Что модель может воспринимать на вход — для рабочих задач

Текст

Письма, документы, анализ, ответы

Код

Скрипты, баги, ревью, объяснение

Изображение

Скриншот → цифры. Фото → аналоги. Скан → текст

Аудио

Записи совещаний → расшифровка. Голосовые → текст

Видео

Ролики → summary, ключевые моменты

Документы

Договоры → риски. Отчёты → тренды. Таблицы → ошибки

Многомодальность

Скрин + вопрос = анализ. Всё вместе

Модели

8 ключевых ИИ-моделей для работы

Claude 4.7

Anthropic • Лидер Arena #1

Плюсы

  • Минимум галлюцинаций — скажет «не уверен»
  • Контекст до 4M токенов (целая книга за раз)
  • Отлично понимает инструкции. Самый «человечный» стиль

Минусы

  • Нет видео и аудио. Дорогой API. Нужен VPN
  • Бесплатно — 45к токенов каждые 3 часа

Для чего

Анализ длинных документов и договоров. Написание сложных текстов. Разработка.

Платный тариф

$18–30/мес — больше лимитов, ранний доступ

GPT-5.4

OpenAI • Самая известная модель

Плюсы

  • Всё-в-одном: текст, код, картинки, видео, голос
  • Экосистема: плагины, GPTs, интеграции везде
  • Голосовой режим. Canvas — совместное редактирование

Минусы

  • Галлюцинирует чаще, чем Claude. Нужен VPN
  • Бесплатно 40–80 сообщений/3ч. Дорогой API

Для чего

Универсальные задачи. Генерация изображений. Голосовые диалоги.

Платный тариф

$20/мес — GPT-5.4 без лимитов, Canvas

Gemini 3.1

Google • Google-экосистема

Плюсы

  • Многомодальность: текст + картинки + видео + аудио
  • 2M контекст — 1500 страниц. Notebook LM
  • Интеграция с Docs, Sheets, Drive, Gmail

Минусы

  • Нужен VPN. Иногда «врёт» увереннее других

Для чего

Работа с Google-экосистемой. Анализ видео. Notebook LM.

Платный тариф

$20/мес — Gemini 3.1 Pro

Perplexity

Perplexity • Поисковик с ИИ

Плюсы

  • Ищет в интернете в реальном времени. Ответы со ссылками
  • Минимум галлюцинаций (опирается на факты)
  • Pro Search по документам. Pro API — 3000/сутки

Минусы

  • Не умеет картинки/видео/аудио. Меньше контекста. VPN
  • Бесплатно ~20 запросов/час

Для чего

Поиск актуальной информации. Фактчекинг. Исследования.

Платный тариф

$20/мес — Pro Search, API

Grok 4

xAI • Доступ к X/Twitter

Плюсы

  • DeepSearch — поиск + X/Twitter в реальном времени
  • Agentic Tasks — модель сама выполняет задачи
  • Voice Mode. SuperGrok — ранний доступ

Минусы

  • Нужен VPN. Бесплатно мало токенов (25/2ч)
  • Менее надёжен для серьёзных задач

Для чего

Мониторинг трендов в X/Twitter. Быстрые задачи с агентами.

Платный тариф

$30/мес — больше токенов, ранний доступ

Kimi 2.6

Moonshot AI • Без VPN

Плюсы

  • Не нужен VPN — работает из России
  • 2M контекст. Agent Swarm — параллельные агенты
  • Long-Context Inferencing. ~100 запросов/мин

Минусы

  • Нет видео и аудио. Интерфейс китайский/английский

Для чего

Длинные документы. Сложные параллельные задачи. Программирование.

Платный тариф

Нет фиксированного — API по расходу

DeepSeek V4

DeepSeek • Цена/качество #1

Минусы

  • Нет видео и аудио. Спартанский интерфейс. Цензура

Для чего

Разработка и API-интеграции. Сложные расчёты (DeepThink).

Задачи по отделам

Как ИИ помогает каждому отделу компании

БУХГАЛТЕРИЯ

Распознавание, сверка, проверка

Задачи

  • Распознавание первичных документов (счета, акты, накладные) → структурированные данные
  • Сверка банковской выписки с 1С и выявление расхождений
  • Проверка правильности проводок и соответствия учетной политике
  • Подготовка форм налоговых деклараций по шаблонам
  • Анализ дебиторской / кредиторской задолженности

Платные ИИ

Claude — лучший для структурирования длинных документов. GPT-4 — универсальный (Canvas для таблиц).

Бесплатные ИИ

DeepSeek — неограниченно, без VPN, отлично справляется с таблицами. Qwen — 120 запросов/мин.

Промпты

1

Я загрузил скан 50 счетов поставщиков. Извлеки из каждого: ИНН, КПП, сумму, дату, номер счета. Сформируй таблицу.

2

Сверь эту банковскую выписку с данными из 1С. Найди расхождения по суммам и датам.

3

Проверь правильность проводки: Дебет 62 Кредит 90 на сумму 150 000 руб. Это реализация услуг.

ФИНАНСЫ

Прогнозирование, бюджеты, сценарии

Задачи

  • Прогнозирование cash flow на основе исторических данных
  • Сценарное моделирование (оптимистичный, реалистичный, пессимистичный)
  • Подготовка отчетности для совета директоров / инвесторов
  • Анализ инвестиционных проектов (NPV, IRR, срок окупаемости)
  • Выявление аномалий в финансовых данных

Платные ИИ

Claude — точность и структура для сложных расчетов. GPT-4 — Canvas для совместной работы с Excel.

Бесплатные ИИ

DeepSeek — DeepThink для сложных расчетов, без VPN. Kimi — 2M контекст для больших таблиц.

Промпты

1

На основе данных о выручке за 24 месяца построй прогноз cash flow на следующие 6 месяцев. Учти сезонность.

2

Построй 3 сценария при росте выручки: +10%, +20%, +30%. Для каждого посчитай EBITDA и точку безубыточности.

3

Проанализируй этот Excel-файл с P&L. Найди 3 главных отклонения от бюджета и объясни причины.

ЮРИСТЫ

Анализ договоров, риски, претензии

Задачи

  • Анализ договоров на предмет рисковых пунктов
  • Сравнение двух редакций одного документа
  • Подготовка претензий, исковых заявлений по шаблонам
  • Проверка compliance с законодательством
  • Поиск судебной практики по аналогичным делам

Платные ИИ

Claude 4 — минимум галлюцинаций, 4M контекст для длинных договоров. GPT-4 — для генерации документов.

Бесплатные ИИ

DeepSeek — без VPN, неограниченно. Perplexity — поиск судебной практики с источниками.

Промпты

1

Проанализируй этот договор поставки. Найди: неблагоприятные условия оплаты, отсутствие штрафных санкций, рисковые пункты о возврате.

2

Рекомендации по работе с ИИ

01

Если не уверены — обсудите с другой моделью

Задайте тот же вопрос Claude, GPT и DeepSeek. Если все три говорят одно — можно доверять.

02

Формулируйте результат, не задачу

Плохо: «Вот отчёт, сделай что-нибудь». Хорошо: «Выдели 3 тренда и предложи 2 действия».

03

Вначале план, потом реализация

Сначала составьте план и согласуйте его. Только потом выполняйте.

04

Заставьте ИИ задать вопросы

«Есть вопросы? Всё ли понятно?» — лучшие результаты даёт диалог, не монолог.

05

Разбивайте сложное на шаги

Не «напиши бизнес-план». Разбейте: структура → рынок → экономика → риски.

06

Давайте контекст

«Ты финдиректор, готовишь презентацию для совета директоров» — результат в разы точнее.

07

Проверяйте факты

ИИ уверенно выдумывает даты и ссылки. Всегда перепроверяйте.

08

Системные промпты для рутины

«Ты аналитик. Каждый CSV → аномалии, топ-3 тренда, рекомендации» — экономит время.

09

Конфиденциальность

Для чувствительных данных — локальные модели (DeepSeek, Qwen) или корпоративные тарифы.

Главное: ИИ — инструмент. Результат зависит от того, насколько точно вы формулируете задачу.
